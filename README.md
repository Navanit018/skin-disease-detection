# Skin Disease Detection System

AI-powered skin disease detection and personalized skincare recommendations.

## Features
- Disease detection from skin images
- Personalized skincare routine based on skin type
- Diet and health tips for healthy skin
- Prediction history

## Technologies
- Python
- TensorFlow (EfficientNet)
- Streamlit

## How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Run app: `streamlit run app_final.py`

## Deployment
Deployed on Streamlit Cloud!

## Model
- Dataset: HAM10000 (10,015 skin lesion images)
- Architecture: EfficientNet-B0 (Transfer Learning)
- Accuracy: ~77% validation accuracy

## Disclaimer
This app is for educational purposes only. Please consult a dermatologist for proper diagnosis.
